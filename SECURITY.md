# Security policy

## Supported versions

The latest release receives fixes.

## Report a vulnerability

1. Do not open a public issue for a security problem.
2. Use the private vulnerability reporting form of the repository, under the Security tab.
3. Describe the problem, the affected version and the steps to reproduce it.

You can expect a first answer within ten working days.

## Scope

The pipeline reads local files and runs a local R script. It opens no network connection and
executes no code taken from its input tables. Reports about data that were exposed by a user, for
example participant data attached to an issue, are also welcome through the same form.
